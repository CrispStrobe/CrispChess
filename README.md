# CrispChess

Cross-platform chess app with pluggable engine backends.

## Engines

| Engine | License | ELO | Status |
|--------|---------|-----|--------|
| CrispEngine (Dart) | MIT | ~1600 | Built-in |
| Frozenight (Rust) | MIT/Apache-2.0 | ~2960 | Planned |
| Stockfish (C++) | GPL-3.0 | ~3600 | Optional, non-iOS |

## Build

```bash
flutter pub get
flutter run
```
