# Privacy Policy — CrispChess

**Last updated:** June 2026

## Short version

CrispChess collects nothing.

## What data is collected

None. This app does not collect, store, or transmit any personal data.

## What happens on your device

- All chess computation runs locally on your device
- Game state exists only in memory and is lost when you close the app
- No data is saved to disk, no cookies, no local storage

## Network

This app makes no network requests. There is no analytics, no tracking,
no advertising, no account system, no telemetry.

## Web version

The web version at crispchess.vercel.app is a static site hosted on Vercel.
Vercel may log standard HTTP access data (IP address, user agent) per their
own privacy policy. CrispChess itself sends no data to any server.

## Third-party services

None. No SDKs, no analytics, no crash reporting.

## Children

This app is safe for all ages. No personal data of any kind is collected,
processed, or transmitted.

## Changes

If we ever add features that involve data storage or network access,
this policy will be updated and any new data collection will be opt-in.
